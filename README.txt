AMELUNA - SITO PRONTO PER GITHUB PAGES

PUBBLICAZIONE:
1. Crea un repository GitHub, per esempio "ameluna".
2. Carica TUTTO il contenuto di questa cartella nella radice del repository.
3. Vai in Settings > Pages.
4. In Build and deployment scegli "Deploy from a branch".
5. Seleziona il branch main e la cartella / (root).
6. Salva: GitHub mostrerà l'indirizzo pubblico.

PROTEZIONI INSERITE:
- nessun pulsante di download;
- pagine del libro convertite in immagini JPG;
- tasto destro disabilitato;
- selezione/copia disabilitata;
- trascinamento immagini disabilitato.

Nessun sito può impedire in assoluto screenshot o recupero tecnico delle immagini dal browser.
